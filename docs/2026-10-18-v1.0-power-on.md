# v1.0 の火入れ結果とジャンパ対応

- 日付: 2026-10-18
- 対象: v1.0（2026-08-12 発注）。BNO055 を除いて実装した状態

## 未配線とジャンパ

電源 LED D1 のアノード側ネット（POWER パッドと R8 の間）に配線が無く、未接続のまま発注した。DRC（KiCad 8.0.7、`unconnected_items`）で 1 件として検出される。実装時にジャンパ線で接続した。

## 火入れ結果

- D1（緑、5V）が点灯: M78AR05-1 の 5V 出力が出ている
- D2〜D6 が点灯: 3.3V が出ていて、6 個とも LED の極性が正しい
- RESET_SW1 を押している間は D2〜D6 が消え、離すと点く: 吸い込み回路が設計どおりで、点灯は Stamp-P4 の出荷時ファームが G37 / G38 / G23 / G19 / G8 を Low にしているため。自作ファームを書き込めば消える

## USB の 5V が基板の 5V 系に流れる（2026-10-22 追記）

- USB-C だけをつないだ状態で D1（5V 電源 LED）が点き、MCP2562 も動いて CAN が通る。Stamp-P4 の VBUS ピン（U1.8）は基板の +5V ネット（M78AR05-1 出力、MCP2562 VDD、D1）に直結している
- 設計時は「Stamp 内部で USB と VBUS ピンを理想ダイオードで OR しているので逆流しない」前提だったが、実物では USB → VBUS ピンの向きに電流が流れる（Stamp-P4 の公式回路図では未確認。データシート上の USB 保護 IC は AW32901 = 過電圧保護スイッチ）
- 影響: 24V と USB を同時につなぐと M78AR05-1 の出力と USB の 5V が並列になる。電圧差は 0.2 V 程度で、実運用（24V を入れたまま USB で書き込み）でも問題は出ていない
- 利点: 5V 系だけで済む動作確認（CAN、LED、Jetson UART の信号）は USB だけで行える。24V が要るのはモータと 7.4V 系（外部 DCDC 経由）だけ

## BNO055 モジュールの実装（2026-10-22 追記）

- AE-BNO055-BO を UART モード（J3 接続、J5 除去）にして丸ピンソケットに実装したところ、USB だけでは D1 と D2 が高速点滅（ブートループ）、24V では ROM 起動ログが 1 回出た後にファームが動かず、3V3 が 0.8 V まで落ちた。モジュールを抜けば正常
- 切り分け: 向き・部品面・ジャンパ・ソケットのブリッジは問題なし。基板のフットプリント（DIP-8、1 = VIN、2/7 = GND、3 = IMU_RX、4 = IMU_TX）もモジュールのピン配置と一致。モジュールをソケットの外に出して VIN / GND だけジャンパ線でつないでもブートループになったため、モジュール内部の電源系（LP5907 入力、FXMA2102 の VCCA、VIN のコンデンサ C2 のいずれか）の短絡で確定。テスターの抵抗レンジでは導通が出ない（半導体性の短絡）
- 原因はジャンパのはんだ作業の熱か静電気か初期不良のいずれかで未特定。モジュールは交換する
- 次のモジュールでは、ジャンパ作業後にソケットへ挿す前に、VIN / GND だけジャンパ線でつないで VOUT（ピン 8）に 2.8 V が出ることを確認してから挿す
- ~~補足: 説明書の回路図では J1〜J3 は 10 kΩ 経由で 2.8 V に、J4 / J5 は GND に直結。J3 と J5 が両方つながっても短絡にはならない~~ → **誤り。下の 2026-11-01 追記を見ること**

## BNO055 モジュールの発熱と原因の確定（2026-11-01 追記）

2 台目のモジュール（J3 を盛って UART 化）でも VOUT（ピン 8）が 0.2 V、挿すとモジュールが熱くなり、基板に挿したまま 1 台目を試したあとは P4 の USB-Serial-JTAG が列挙されなくなった（3V3 が落ちている）。モジュールを抜けば正常。

- 基板側の導通確認（ソケットの 8 ピンすべて: 1 = 3V3、2 / 7 = GND、3 = G15、4 = G12 に 10 kΩ プルアップ、5 / 6 / 8 = 未接続）は**すべて正常**。基板は白
- 無電源でモジュール単体を測ると **VOUT–GND が短絡**、VIN–GND と VIN–VOUT は正常。J3 の横の 10 kΩ は 10 kΩ のまま。**J5 の残りはんだを完全に除去したら VOUT–GND の短絡が消えた**
- 結論: **J3 と J5 が同時に閉じていると VOUT（2.8 V）が GND に短絡し、LP5907 が電流制限で発熱する**。説明書の回路図の読み（10 kΩ 経由）は実物と合っていない。1 台目も「J3 を盛って J5 を外しきれていなかった」状態で通電したことで入力側まで焼けたと考えるのが自然
- 復活した 2 台目を基板に挿し、ファーム（UART）で RUNNING・約 100 サンプル/s・ジャイロ校正完了を確認。運用は UART モードで確定

**組立手順（確定）**: (1) **先に J5 のはんだを完全に除去**し、無電源で J5 の両パッド間が開放であることをテスターで確認。(2) そのあと J3 にはんだを盛る。(3) 無電源で VOUT（ピン 8）–GND が高抵抗（数 kΩ 以上）であることを確認。(4) 可能なら VIN / GND だけに 3.3 V を与えて VOUT 2.8 V・発熱なしを確認してから挿す。J4 は接続のまま、J2 / J1 は触らない。

## 次の改版で

- D1 周りの配線を引き直し、DRC の未接続 0 件を確認してから発注する
- サーマルリリーフ不足 5 件とシルクの警告も確認する
- Stamp の VBUS ピンと M78AR05-1 出力の間に逆流防止（理想ダイオード IC かショットキー）を入れ、24V と USB の同時接続で 2 つの 5V 源が並列にならないようにする

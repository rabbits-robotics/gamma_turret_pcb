# v1.0 の火入れ結果とジャンパ対応

- 日付: 2026-10-18
- 対象: v1.0（2026-08-12 発注）。BNO055 を除いて実装した状態

## 未配線とジャンパ

電源 LED D1 のアノード側ネット（POWER パッドと R8 の間）に配線が無く、未接続のまま発注した。DRC（KiCad 8.0.7、`unconnected_items`）で 1 件として検出される。実装時にジャンパ線で接続した。

## 火入れ結果

- D1（緑、5V）が点灯: M78AR05-1 の 5V 出力が出ている
- D2〜D6 が点灯: 3.3V が出ていて、6 個とも LED の極性が正しい
- RESET_SW1 を押している間は D2〜D6 が消え、離すと点く: 吸い込み回路が設計どおりで、点灯は Stamp-P4 の出荷時ファームが G37 / G38 / G23 / G19 / G8 を Low にしているため。自作ファームを書き込めば消える

## USB の 5V が基板の 5V 系に流れる（2026-10-22 追記）

- USB-C だけをつないだ状態で D1（5V 電源 LED）が点き、MCP2562 も動いて CAN が通る。Stamp-P4 の VBUS ピン（U1.8）は基板の +5V ネット（M78AR05-1 出力、MCP2562 VDD、D1）に直結している
- 設計時は「Stamp 内部で USB と VBUS ピンを理想ダイオードで OR しているので逆流しない」前提だったが、実物では USB → VBUS ピンの向きに電流が流れる（Stamp-P4 の公式回路図では未確認。データシート上の USB 保護 IC は AW32901 = 過電圧保護スイッチ）
- 影響: 24V と USB を同時につなぐと M78AR05-1 の出力と USB の 5V が並列になる。電圧差は 0.2 V 程度で、実運用（24V を入れたまま USB で書き込み）でも問題は出ていない
- 利点: 5V 系だけで済む動作確認（CAN、LED、Jetson UART の信号）は USB だけで行える。24V が要るのはモータと 7.4V 系（外部 DCDC 経由）だけ

## 次の改版で

- D1 周りの配線を引き直し、DRC の未接続 0 件を確認してから発注する
- サーマルリリーフ不足 5 件とシルクの警告も確認する
- Stamp の VBUS ピンと M78AR05-1 出力の間に逆流防止（理想ダイオード IC かショットキー）を入れ、24V と USB の同時接続で 2 つの 5V 源が並列にならないようにする

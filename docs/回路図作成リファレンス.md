## 4. 検証の現状ルール

- 結線照合: `python check_nets.py` → `OK: all nets match` が正常（expected_nets.csvが正解表）
- ERC: **エラー3件（+24V・GND・+7.5Vの電源未駆動）は許容ベースライン**（PWR_FLAG非採用の設計判断による）。これ以外のエラー・警告が出たら要調査
- 未対応事項: アノテーション警告（実害なし・自作シンボルのReference設定が有力容疑）
